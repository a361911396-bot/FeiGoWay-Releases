# 飞构卫 FeiGoWay V1

**让重要文件有版本，让电脑使用有记录，让异常操作更容易回顾。**

FeiGoWay 是面向 Windows 10 / 11 的本地优先工具，将文件保护、窗口活动追踪、操作触发截图等能力集中在一个桌面客户端中。它帮助你回顾电脑上发生过什么，并为重要文件保留可恢复的历史版本。

[下载最新安装包](https://github.com/a361911396-bot/FeiGoWay-Releases/releases/latest) · [官方网站](https://www.feigoway.cn/) · [使用教程](https://www.feigoway.cn/guide/computer-usage-record)

## 谁适合使用

- **设计师、内容创作者**：设计稿、素材和交付文件反复修改时，保留变化线索，减少覆盖错误带来的损失。
- **自由职业者、文档工作者**：为合同、方案、报价表和客户文件启用保护，需要时查看文件事件与已有备份。
- **成年学生、研究人员、开发者**：为论文、作业或项目文件保留版本，辅助回顾个人电脑上的应用使用情况。
- **希望复盘效率的个人用户**：查看应用使用时长、排行与活动时间线，了解时间主要花在哪里。
- **需要排查误操作的人**：结合窗口记录、文件事件和操作截图，定位值得进一步检查的时段；这些线索不等于完整审计或取证结论。

家庭共用或他人使用的设备，必须先获得适当授权并明确告知记录范围。本产品不是用于隐蔽监视他人的工具。

## 功能与真实界面

以下为官网公开的客户端界面截图。截图中的账号状态、记录数据、套餐额度及界面细节仅用于展示，不代表你的实际数据或当前购买权益；以当前客户端和购买确认页为准。

### 1. 文件保护：重要文件不只保留最后一次修改

添加需要保护的文件夹或文件，开启监控后记录受保护范围内的创建、修改与删除事件，并按功能规则保存历史版本。需要找回内容时，可查看已有版本并选择恢复。

适用于文档覆盖、设计稿误改等场景。**恢复依赖事先生成且仍可用的备份，事后安装无法补回过去的文件版本**；重要文件仍建议另做独立备份。

![文件保护：保护范围、文件事件与历史版本](https://www.feigoway.cn/screenshots/file-protection.png)

### 2. 窗口追踪：把分散的应用使用整理成时间线

记录客户端运行且追踪开启期间的应用活动与窗口切换，查看使用汇总、应用排行和活动时间线，帮助你回顾工作节奏或定位异常时段。

应用使用时长不等同于工作产出，也不能单凭窗口记录判断是谁操作或是否发生信息泄露。

![窗口追踪：应用时长、分类与活动时间线](https://www.feigoway.cn/screenshots/window-tracking.png)

### 3. 操作记录：在特定操作发生时保存画面

可按设置在检测到特定截图或文件复制操作时保存屏幕画面，并查看、管理或批量删除已有记录。它是操作触发记录，不是连续录像，也不保证捕获所有操作。

截图可能包含文档、聊天或其他敏感内容，请谨慎选择启用范围、保存时间和设备使用场景。

![操作记录：触发设置与本地记录管理](https://www.feigoway.cn/screenshots/screenshots.png)

### 4. 辅助安全检测

提供监控软件相关检测与安全管理辅助能力，帮助发现需要进一步核查的线索。检测结果需要结合实际情况判断，不能替代专业杀毒、安全审计或取证服务。

## 第一次使用

1. 从本仓库的 Release 下载 `.exe` 安装包；`Source code` 压缩包不是安装程序。
2. 安装并按客户端提示完成账号与设备设置，了解可用功能和订阅权益。
3. 在“文件保护”中添加重要文件，确认监控状态；按需要开启窗口追踪和操作记录。
4. 使用一段时间后查看事件、时间线与已有版本。先用测试文件验证备份及恢复，再应用到重要工作文件。

## English overview

FeiGoWay is a local-first Windows 10 / 11 desktop application for protected-file history, application activity timelines, event-triggered screenshots, and auxiliary security checks. It is designed for document workers, designers, freelancers, adult students, researchers, developers, and users reviewing their own computer activity.

Records depend on the application running and the relevant features being enabled. Recovery requires existing backups. The software does not reconstruct past activity, continuously record every action, or replace professional security or forensic tools. Use it only with appropriate authorization and informed consent.

This repository distributes proprietary installers, not product source code. Some features require an account and subscription. See the website for privacy, pricing, and current feature availability.
